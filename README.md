# GFL2 Guild OCR 배포

GFL2 길드의 공적·흙먼지 화면을 OCR로 읽고 주간 점수를 관리하는 Windows 프로그램의 공식 배포 저장소입니다.

- 현재 공개 버전: **v0.1.3** (DB Schema 5)
- 지원 환경: Windows 64비트. Python 별도 설치 불필요
- [공식 v0.1.3 다운로드](https://github.com/busikang/gfl2-guild-ocr-releases/releases/tag/v0.1.3)
- [최신 온라인 사용설명서](사용설명서.txt)

## 설치

1. 배포 페이지에서 `GFL2GuildOCR-v0.1.3-win-x64.zip`을 내려받습니다.
2. ZIP을 원하는 위치에 **전체 압축 해제**합니다.
3. `GFL2GuildOCR` 폴더 전체를 유지한 채 그 안의 `GFL2GuildOCR.exe`를 실행합니다.

EXE만 따로 복사하거나 `_internal` 폴더를 삭제하지 마세요. ZIP 내부 설명서는 해당 바이너리를 만들 당시 내용이며, 이후 정리된 안내는 위 온라인 사용설명서에서 확인할 수 있습니다.

## 주요 기능과 데이터

게임 창 캡처·한국어/영어 OCR, 공적·흙먼지 주간 시트, 길드원·별칭 관리, 점수 근거 확인·수정, CSV 내보내기와 업데이트 확인을 제공합니다.

사용자 기록은 프로그램 폴더와 별도의 `%LOCALAPPDATA%\GFL2GuildOCR`에 저장됩니다. 업데이트할 때 이 데이터 폴더를 삭제하지 마세요. 프로그램 안에서는 `도움말 → 업데이트 확인`을 사용할 수 있습니다.

ZIP의 SHA-256은 같은 버전 Release의 `SHA256SUMS.txt`와 `update-manifest.json`에서 확인하세요. 다른 버전의 해시와 비교하지 마세요.

## v0.1.3 변경 및 구버전 업데이트

- 실사용 검증된 흙먼지·과업 주간 경계 수정과 이벤트 날짜별 과업 총상한 적용을 포함합니다. 저장된 상한은 자동으로 올리지 않으며, '흙먼지 / 90'은 참여 기준이 아니라 총상한 90입니다. 실제 총상한을 해당 주간에 적용하세요.
- 미확정 원인과 단일 Accepted 기록 안내를 개선했습니다. OCR 원본·채택 기록·수동 점수 및 멤버 식별 규칙은 보존합니다.
- 새 업데이터는 한글·공백이 있는 설치 폴더 이름도 유지합니다.

v0.1.1·v0.1.2의 기존 업데이터에는 폴더명 제한이 남아 있습니다. 기존 설치 폴더명이 `GFL2GuildOCR`이면 일반 자동 업데이트가 가능합니다. 이름을 변경한 사용자는 모든 앱을 종료하고 폴더명을 `GFL2GuildOCR`로 임시 변경해 업데이트하세요(기존 폴더를 덮어쓰지 마세요). v0.1.3 설치 후 원하는 이름으로 바꾸거나 검증된 업데이터 패치를 사용할 수 있습니다. 사용자 데이터 폴더는 삭제·초기화하지 마세요. 기존 v0.1.2 ZIP·태그·Release는 유지합니다.

이 저장소에는 공개 배포 파일과 사용자 문서만 제공하며, 개발 소스 저장소는 비공개입니다.
