# GFL2 Guild OCR 배포

GFL2 길드의 공적·흙먼지 화면을 OCR로 읽고 주간 점수를 관리하는 Windows 프로그램의 공식 바이너리 배포 저장소입니다.

- 현재 공개 버전: **v0.1.8** (Database Schema 5)
- 지원 환경: Windows 64비트. Python을 별도로 설치할 필요가 없습니다.
- [공식 v0.1.8 다운로드](https://github.com/busikang/gfl2-guild-ocr-releases/releases/tag/v0.1.8)
- [최신 온라인 사용설명서](사용설명서.txt)

## 설치와 업데이트

`GFL2GuildOCR-v0.1.8-win-x64.zip` 전체를 압축 해제한 뒤, `GFL2GuildOCR` 폴더 안의 `GFL2GuildOCR.exe`를 실행하세요. EXE만 옮기거나 `_internal` 폴더를 삭제하지 마세요. OCR 모델과 TXT 설명서가 포함됩니다.

기존 프로그램의 `도움말 → 업데이트 확인`에서도 새 버전을 확인할 수 있습니다. 사용자 승인 후 ZIP 크기·SHA-256 검증, DB 백업, 프로그램 교체를 진행합니다. 사용자 기록은 프로그램 폴더와 별도인 `%LOCALAPPDATA%\GFL2GuildOCR`에 저장됩니다. 이 데이터 폴더를 삭제·초기화하지 마세요. 별도 격리 실행기를 쓰는 경우 해당 실행기가 지정한 프로필을 사용합니다.

v0.1.3부터 업데이터가 한글·공백 설치 폴더명을 유지합니다. v0.1.1·v0.1.2의 기존 업데이터에는 폴더명 제한이 있으므로, 이름을 변경했다면 앱을 종료하고 `GFL2GuildOCR`로 임시 변경하거나 검증된 업데이터 패치를 사용하세요. 기존 폴더를 덮어쓰지 마세요.

## v0.1.8 주요 변경

- 과업 카드의 실제 닉네임 줄을 구분하여 배경의 `#404` 같은 장식 문구가 이름에 붙는 문제를 개선했습니다.
- 실제 이름의 공백·숫자·특수문자를 유지합니다. 구분이 불명확하면 행과 점수를 보존하고 확인 필요로 표시합니다.
- 기존 EasyOCR CPU 모델·낮은 신뢰도 안내·별칭 연결·과업/흙먼지 계산·Raw/Accepted/MANUAL·업데이터와 Schema 5를 유지합니다. 새 마이그레이션이나 시작 시 일괄 재작성은 없습니다.

## 이전 v0.1.7 주요 변경

- 흙먼지는 각 카드의 순위 배지·Lv/직급·행 경계·점수 컬럼을 독립 검증합니다. 초상화 테두리가 불완전해도 근거가 충분한 정상 카드는 읽고 불확실한 구조는 차단합니다.
- 같은 캡처의 일반·하단 고정 카드가 순위·이름·두 점수까지 일치하고 순위 근거가 충분할 때만 한 행으로 처리합니다. 불일치나 불확실한 순위는 확인 필요이며 원본 근거를 보존합니다.
- 과업 OCR에서 이름 토큰이 빠져도 실제 회원 카드의 행을 보존합니다. 해당 카드 안에서만 재인식하며 이름·숫자 미인식은 확인 필요로 표시합니다. 다른 행의 점수를 빌리거나 누락 숫자를 0점으로 만들지 않습니다.
- 기존 EasyOCR CPU 모델·명시적 별칭 연결·숫자 검증·Raw/Accepted/MANUAL·독립 계산·결산·Schema 5를 유지합니다. 새 마이그레이션이나 시작 시 일괄 재작성은 없습니다. 이름 오인식은 여전히 가능하며 모든 해상도·DPI의 완전 인식을 보장하지 않습니다.

## 이전 v0.1.6 주요 변경

- 실제 랭킹 카드·행·컬럼 위치로 이름과 두 점수를 독립 인식하여 같은 행끼리 결합합니다. 기존 EasyOCR CPU 모델과 명시적 별칭 연결을 유지하며 지원하지 않는 구조는 오류로 알립니다.
- 숫자 누락·잘못된 쉼표·비정수 k를 0점 등 정상값으로 만들지 않습니다. 이름 수정·별칭·행 합치기로 숫자 검증을 우회하지 못하게 하고 실제 0점과 정상 수동 교정은 유지합니다.
- 기본식은 현재 Accepted 누적에서 이전 Accepted 누적을 차감합니다. 상한 초과·누락 구간은 최근 날짜부터 최대점수 우선으로 운영 배분하며 Raw·기존 Accepted·MANUAL을 보호합니다.
- `RULE_CONFIRMED`는 운영 규칙 확정이지 실제 플레이 시각의 증명이 아닙니다. 관측 0점과 최종 0점, 근거 충돌을 구분합니다.
- 게임 날짜는 KST 05:00에 바뀌고 이벤트 종료는 일요일 02:00입니다. 결산 대기 이벤트는 05:00 이후에도 대상 이벤트 ID·기간과 최종 랭킹임을 확인한 창 캡처를 마지막 토요일에 반영할 수 있습니다. 화면만으로 이벤트 소속을 자동 판단하지 않습니다.
- 결산 확인 시 미기록·미확정 Daily를 스냅샷에서만 `0 (결산)`으로 처리합니다. 최신 유효 Accepted 누적을 우선하고 일일 합계와의 차이는 근거와 함께 보존합니다. 실제 OCR 0·수동 0·결산 0은 구별되며 결산 후 변경은 차단됩니다.
- 일일 점수컷과 시즌 점수컷(일일 ×7), 최소 적합(일일 ×6)을 표시합니다. 진행 중 합계는 최신 유효 누적, 최종 판정은 05:00 이후 또는 명시적 결산 후 적용합니다.
- 과업·흙먼지 독립 계산, 기존 과업 계산, 길드원·별칭·탈퇴·복귀·기존 결산, 한글·공백 폴더명 업데이트와 Schema 5를 유지합니다. 새 마이그레이션이나 기존 데이터의 시작 시 일괄 재작성을 추가하지 않습니다.

ZIP의 SHA-256은 같은 Release의 `SHA256SUMS.txt`와 `update-manifest.json`에서 확인하세요. 버전이 다른 파일의 해시와 비교하지 마세요. 기존 v0.1.7 이하 자산·태그·Release는 보존됩니다.
