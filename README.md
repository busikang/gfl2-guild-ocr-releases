# GFL2 Guild OCR 배포

GFL2 길드의 공적·흙먼지 화면을 OCR로 읽고 주간 점수를 관리하는 Windows 프로그램의 공식 바이너리 배포 저장소입니다.

- 현재 공개 버전: **v0.1.4** (Database Schema 5)
- 지원 환경: Windows 64비트. Python을 별도로 설치할 필요가 없습니다.
- [공식 v0.1.4 다운로드](https://github.com/busikang/gfl2-guild-ocr-releases/releases/tag/v0.1.4)
- [최신 온라인 사용설명서](사용설명서.txt)

## 설치와 업데이트

`GFL2GuildOCR-v0.1.4-win-x64.zip` 전체를 압축 해제한 뒤, `GFL2GuildOCR` 폴더 안의 `GFL2GuildOCR.exe`를 실행하세요. EXE만 옮기거나 `_internal` 폴더를 삭제하지 마세요. OCR 모델과 TXT 설명서가 포함됩니다.

기존 프로그램의 `도움말 → 업데이트 확인`에서도 새 버전을 확인할 수 있습니다. 사용자 승인 후 ZIP 크기·SHA-256 검증, DB 백업, 프로그램 교체를 진행합니다. 사용자 기록은 프로그램 폴더와 별도인 `%LOCALAPPDATA%\GFL2GuildOCR`에 저장됩니다. 이 데이터 폴더를 삭제·초기화하지 마세요. 별도 격리 실행기를 쓰는 경우 해당 실행기가 지정한 프로필을 사용합니다.

v0.1.3부터 업데이터가 한글·공백 설치 폴더명을 유지합니다. v0.1.1·v0.1.2의 기존 업데이터에는 폴더명 제한이 있으므로, 이름을 변경했다면 앱을 종료하고 `GFL2GuildOCR`로 임시 변경하거나 검증된 업데이터 패치를 사용하세요. 기존 폴더를 덮어쓰지 마세요.

## v0.1.4 주요 변경

- 과업과 흙먼지 점수 계산을 독립화했습니다. 과업 누락·미확정·참여 기준이 흙먼지 계산을 차단하지 않습니다.
- 흙먼지 Accepted 누적·관측시각·이벤트 기간·일일 최대점수로 가능한 날짜별 배분이 하나일 때만 자동 확정합니다.
- 여러 배분이 가능하면 미확정으로 남깁니다. 관측 시점의 0점과 확정 0점을 구분하고, 점수를 자르거나 초과분을 무조건 전날에 넣지 않습니다.
- 과업 기존 계산, 수동 확정, OCR Raw/Accepted, 길드원 ID·별칭, 최종일·결산 보호 및 Schema 5를 유지합니다.
- 기존 기록을 실행 직후 일괄 재확정하지 않습니다. 자세한 내용은 Release 설명과 사용설명서를 확인하세요.

ZIP의 SHA-256은 같은 Release의 `SHA256SUMS.txt`와 `update-manifest.json`에서 확인하세요. 버전이 다른 파일의 해시와 비교하지 마세요. 기존 v0.1.3 자산·태그·Release는 보존됩니다.

이 저장소는 공개 배포 파일과 사용자 문서만 제공합니다. 개발 소스 저장소는 비공개입니다.
